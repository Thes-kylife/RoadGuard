
# RoadGuard - Features

## 1. AI Pothole Detection
Identifies potholes from camera images using an AI detection model.

## 2. GPS Tracking
Records the geographical location of detected potholes.

## 3. Hazard Map
Displays reported potholes on an interactive map.

## 4. Community Reporting
Allows users to submit pothole and road damage reports.

## 5. Voice Warnings
Provides audio alerts about nearby road hazards.

## 6. Dashboard
Displays reports, statistics and road condition information.

## 7. Accelerometer Support
Explores smartphone motion sensors to help identify possible road irregularities.

## Note
Features are under development and will be updated as they are implemented and tested.
