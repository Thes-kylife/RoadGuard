
# RoadGuard - Testing Plan

## 1. Frontend Testing
- Check whether all pages load correctly.
- Test navigation and buttons.
- Check mobile responsiveness.

## 2. Backend Testing
- Verify API endpoints.
- Test report submission.
- Test report retrieval.
- Check error handling.

## 3. Database Testing
- Verify MongoDB connection.
- Check whether reports are saved correctly.
- Test retrieving stored reports.

## 4. AI Testing
- Test pothole detection using sample images.
- Check detection results.
- Evaluate detection accuracy.

## 5. GPS and Map Testing
- Check location permission.
- Verify GPS coordinates.
- Check whether reports appear on the map.

## Testing Status
Testing activities will be updated as the application is developed.
